01 / DESIGN QUESTION

THE
PROBLEM
TO STUDY.

Carcassonne is a tile-placement game where players shape a shared medieval landscape and claim cities, roads, monasteries and farms. BoardGameGeek lists the game at 2–5 players, 30–45 minutes, with a community complexity weight of 1.88/5. The interesting design problem is how that relatively light ruleset produces strategic depth.
HOW DOES ONE SIMPLE ACTION CREATE MULTIPLE COMPETING DECISIONS?

Build the map.

Each placed tile permanently changes the shared spatial state.

Claim the value.

A meeple converts a promising feature into a temporary ownership commitment.

Read everyone.

Your best placement is also evaluated through what it gives, denies or exposes to opponents.

Plan the future.

The important consequence of a tile is often not its immediate points, but what it makes possible next.

03 / TILE PLACEMENT

THE BOARD
IS THE
PUZZLE.

Tile placement is more than matching edges. It is a spatial decision with immediate, competitive and future consequences.
TILE LANGUAGE / ROADS · CITIES · FIELDS · MONASTERIES DIAGRAM · CC BY-SA
READ THE TILE

LEGALITY → VALUE → DENIAL

Legality: where can this tile fit?

Value: which placement advances my plan?

Denial: which placement changes another player's future options?

DESIGN TAKEAWAY

A tile is a constraint package. Its value depends on the board state surrounding it.

SYSTEM PRINCIPLE

Do not measure depth by action count.

Carcassonne keeps the action vocabulary small and moves complexity into consequence: placement changes ownership, scoring opportunities, future paths and other players' options.

04 / MEEPLE SYSTEM

OWNERSHIP
IS A
RESOURCE.

Meeples make otherwise passive map features strategically meaningful. Committing one means giving up the chance to use that worker somewhere else until the feature resolves.
COMMITMENT LOOP

AVAILABLE → COMMIT → COMPLETE → RETURN

The meaningful question is not simply “can I claim this?” but: “Is this opportunity worth locking a limited resource into?”

This converts a physical worker into a lightweight economy of opportunity cost.

DESIGN TAKEAWAY

Scarcity gives ownership weight. A commitment only matters when alternatives exist.

05 / SCORING

SCORE
SHAPES
BEHAVIOUR.

Cities, roads, monasteries and fields create different spatial goals. The scoring system therefore acts as a behavioural guide rather than just an end-of-turn calculator.
MULTIPLE FORMS OF VALUE

THE SAME BOARD CAN BE READ IN DIFFERENT WAYS.

City: expansion and enclosure.

Road: extension and connection.

Monastery: surrounding-space completion.

Field: long-horizon regional influence.

DESIGN TAKEAWAY

If several scoring structures coexist, players can pursue different definitions of “good space.”

06 / RISK & COMMITMENT

BIGGER
IS NOT
ALWAYS BETTER.

Larger features may offer more potential value, but they can also remain unresolved longer, keep meeples committed and become exposed to more board-state changes.
01

SMALL FEATURE

Fast completion and quicker resource recovery.

02

LARGE FEATURE

Higher potential value with greater completion dependency.

03

RESOURCE LOCK

A committed meeple reduces your available options.

04

OPPONENT PRESSURE

The shared map can change before your plan resolves.

05

LONG HORIZON

Fields and unfinished structures move value toward the end game.

DESIGN TAKEAWAY

Risk can come from commitment and time — not only from probability.

A design can create tension by asking players to lock resources into uncertain future outcomes. No dice roll is required.

07 / PLAYER INTERACTION

COMPETE
WITHOUT
AN ATTACK BUTTON.

Carcassonne creates multiplayer pressure through the shared map. Players can block, connect, contest and exploit opportunities through placement itself.
SHARED SPACE / FIVE-PLAYER MID-GAME STATE PHOTO · JIP / CC BY-SA
INTERACTION LANGUAGE

BLOCK · JOIN · CONTEST · OPPORTUNISM

Block: reduce useful completion possibilities.

Join: connect into a shared feature when the rules allow it.

Contest: compete for control where the scoring rules create it.

Opportunism: gain value from a landscape another player helped construct.

DESIGN TAKEAWAY

The system itself can be the medium of conflict. Direct combat is not required for strong player interaction.

THE MAP IS NOT A BACKDROP. IT IS WHERE THE PLAYERS INTERACT.
08 / INFORMATION DESIGN

THE MAP
IS THE
INTERFACE.

Important state is represented spatially: open edges, completed features, claimed locations, feature boundaries and the overall shape of the growing board.
VISIBLE GAME STATE

POSITION COMMUNICATES POSSIBILITY.

Players do not need a separate HUD to understand much of the game. The geometry of the board tells them what has been built, what remains open and which spaces can support future action.

LEVEL DESIGN CONNECTION

Readable spatial structure can communicate state and future options before explicit interface elements are added.

10 / RANDOMNESS & AGENCY

THE TILE
IS RANDOM.
THE DECISION ISN'T.

The draw creates uncertainty. The player then receives agency over interpretation: where the tile goes, whether to claim it and how that choice changes the map.

Random input

DrawYou do not choose the tile that appears.
ConstraintThe board limits where that tile can produce useful value.
UncertaintyFuture options depend on what is drawn later.

Player agency

InterpretSearch the current map for useful placements.
CommitChoose whether a meeple is worth spending.
TransformYour placement permanently changes the next decision state.
DESIGN TAKEAWAY

Randomness creates the problem. Agency determines how the problem is solved.

The useful distinction is not “random or strategic.” It is whether uncertainty is followed by enough meaningful decisions for the player to feel responsible for the outcome.

How I would present revenue in a portfolio.

A verified publisher financial statement for Carcassonne's lifetime revenue was not found. A 2026 third-party statistics report estimates the wider franchise at over $400 million lifetime revenue, while reporting 12M+ base-game copies and 6M+ expansion units.

Important: the $400M+ figure is an estimate, not an audited Asmodee/Hans im Glück revenue disclosure. I would label it exactly that way rather than presenting it as official revenue. I would also avoid multiplying today's MSRP by copies sold because historical prices, editions, expansions and retailer margins make that calculation misleading.

12 / WHAT I LEARNED

DESIGN
TAKEAWAYS.

The goal of this breakdown is to extract reusable design principles, not to memorize Carcassonne's rules.
01

Simple actions can create deep decisions.

Increase consequences and context before increasing the number of player verbs.

02

Scarcity makes ownership meaningful.

A claim matters because the same worker cannot be committed everywhere at once.

03

Scoring rules are behavioural rules.

What the game rewards changes what players consider valuable space.

04

Shared space naturally creates interaction.

Competition can emerge through placement without explicit attack mechanics.

05

Random input can preserve agency.

Uncertainty is useful when players retain meaningful choices after the random event.

06

Commitment can generate risk.

Resource lock and delayed completion are enough to create tension.

07

Spatial readability can replace interface.

The board itself communicates ownership, state and future possibility.

08

Depth can emerge from small systems interacting.

Tile rules + scoring + resources + opponents create complexity without a huge ruleset.

FINAL DESIGN STATEMENT

DESIGN CONSEQUENCES,
NOT COMPLEXITY.

Carcassonne turns a single repeated action into a chain of consequences: SPACE → OWNERSHIP → RESOURCE COMMITMENT → SCORING → OPPONENT IMPACT → FUTURE POSSIBILITY.

My main takeaway: a simple mechanic becomes deep when every decision changes the context of the next decision.
